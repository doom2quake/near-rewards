Settlemint · NEAR Protocol

A market that settles itself, to the last yocto.

One resolver key opens a Yes/No event market on NEAR. Stakers commit yoctoNEAR while it is open. When the outcome is known, an operator agent resolves once and pays every winner pro rata in a single pass. The last winner sweeps the rounding dust, so escrow lands at exactly zero and no stake is ever stranded. If the resolver never shows up, anyone can void the market after a grace window and every staker withdraws their own stake. Press run and watch the escrow drain to zero.
